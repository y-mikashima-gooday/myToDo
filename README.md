# TaskMaster Pro (myToDo)

付箋のようなシンプルさと使いやすさを追求した、GoogleカレンダーのToDoリストを補完するWebタスク管理アプリケーションです。

---

## 🌟 主な特徴・機能

* **左右2分割レイアウト (1:3 比率)**
  * **左エリア (1/4幅)**: タスクの新規追加フォームおよび検索・並び替えコントロール（固定表示）
  * **右エリア (3/4幅)**: 大量のタスクを一度に見渡せるコンパクトな1行表示リスト（独立スクロール可能）
* **フレキシブルな日時管理**
  * 日付（必須）と時間（任意・省略可能）の個別入力に対応
  * 時間を省略した場合、その日の 23:59:59 を締め切りとして自動処理
* **期限切れ通知機能**
  * 現在時刻を超過した未完了タスクを「⚠️ 期限切れ」バッジおよび赤色背景でリアルタイムに強調表示
  * 完了済みに切り替えると警告表示を自動解除
* **柔軟なソート＆フィルタリング**
  * 「優先度順（高・中・低）」「日付順（昇順）」のリアルタイム並び替え
  * キーワード検索およびステータス（すべて／未完了／完了済み）絞り込み
* **完全ローカル保存**
  * ブラウザの `localStorage` を使用するため、サーバーへの登録不要でデータが保持されます

---

## 📁 構成ファイル

* `index.html` - アプリケーションの画面構造（2列レイアウト・フォーム）
* `style.css` - ニューモフィズム風デザイン・レスポンシブ対応・期限切れ警告スタイル
* `script.js` - タスク追加・削除・完了・検索・ソート・期限切れ判定のフロントエンド処理
* `app.py` - ローカル検証用の軽量Webサーバー (Python)
